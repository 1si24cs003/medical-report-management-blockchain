Academic Architecture

System Objectives & Innovation Pillars

Engineered to satisfy core computer science and distributed systems deliverables, resolving real-world healthcare vulnerabilities with decentralized consensus algorithms.

Academic Objective 1 & 3

Chronological Longitudinal Patient Timeline

Consolidates fragmented historical visits across disparate consortium hospitals into an interactive, chronological timeline grouped by hospital node and specialty.

Academic Objective 2

Prevention of Duplicate Report Generation

Employs deterministic SHA-256 pre-flight cryptographic hashing to detect and reject duplicate diagnostic uploads instantaneously before ledger anchoring, saving critical hospital resources.

Key Feature 7.1

QR Code Anti-Forgery Cryptographic Proof

Embeds verifiable HMAC-SHA-256 QR codes on every generated report, enabling instant verification on paper or screen against the immutable blockchain ledger.

Key Feature 7.2

Time-Expiring Secure Access Token Links

Granular patient-governed record sharing with time-limited cryptographic tokens (1h, 24h, 7d) that self-expire automatically, preventing unauthorized secondary record dissemination.

Key Feature 7.3

Hybrid Gemini AI Clinical Synthesis

Autonomous clinical highlights engine powered by Gemini AI with built-in offline NLP fallback, synthesizing complex diagnostics into clear summaries for attending doctors.

System Security

Role-Based Access Control (RBAC) & AES-256

Strict segregation of duties across Doctor, Lab Staff, Patient, and Admin identities, paired with AES-256-CBC off-chain encryption and on-chain hash verification.

Live Cryptographic Audit

Instant Report Integrity Verifier

Publicly audit any HealthChain medical report against the immutable distributed ledger. Enter any Report ID (e.g. REP-101, REP-102) to verify its block seal and cryptographic hash in real time.
