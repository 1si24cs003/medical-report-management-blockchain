Objective 2: Duplicate Detection Engine

Cryptographic SHA-256 fingerprint comparison prior to blockchain recording

When an authorized staff member attempts to upload a medical report, the backend computes its SHA-256 hash. If this hash already matches an existing block on the blockchain, the upload is rejected with HTTP 409 Conflict. This prevents redundant storage and guarantees a single verified reference for each diagnostic document.
